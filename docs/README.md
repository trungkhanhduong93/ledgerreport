# iPOS Accounting Report Landing Page

Trang Landing Page tải ứng dụng **iPOS Accounting Report** (`.exe`).

## Cấu trúc file:
- `index.html`: Giao diện chính (HTML5 + SEO).
- `style.css`: Hệ thống thiết kế chuẩn tone iPOS.vn (Cam Coral & Navy Slate).
- `app.js`: Tự động đồng bộ thông tin phiên bản mới nhất từ GitHub Releases API.

## Cách mở & chạy thử:
1. Mở trực tiếp file `index.html` trong bất kỳ trình duyệt nào (Chrome, Edge, Firefox).
2. Hoặc bật GitHub Pages trong cài đặt repo `trungkhanhduong93/ledgerreport` (Settings -> Pages -> Branch main / docs folder).
