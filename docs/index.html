Tính Năng Vượt Trội

Tối Ưu Hóa Quy Trình Báo Cáo Kế Toán iPOS

Được xây dựng chuyên biệt cho hệ thống dữ liệu F&B và bán lẻ của iPOS ACC, giải quyết triệt để bài toán xử lý dữ liệu lớn.

Bộ Báo Cáo BC001 — BC014

Đầy đủ Bảng Cân Đối Kế Toán, Kết Quả HĐKD, Lưu Chuyển Tiền Tệ (TT200 & Chú Long), Báo Cáo Công Nợ và Sổ Chi Tiết Tài Khoản.

Danh Sách Tồn Kho Thực Tế

Theo dõi tồn kho 3 chiều (Đơn vị × Kho × Hàng hóa) từ bảng WAREHOUSE_BALANCE_ACTUAL, hỗ trợ cả Số lượng nguyên & ĐVT nguyên.

Xuất Excel & CSV Siêu Tốc

Tối ưu hóa bộ nhớ và xuất file dữ liệu lớn cực nhanh. Đã kiểm thử thực tế với 107.499 dòng: CSV chỉ mất ~4s, XLSX mất ~14s.

Tra Cứu Đối Ứng Chi Tiết

Tra cứu sâu từng chứng từ, bút toán nợ/có đối ứng, tài khoản chi tiết và thông tin người lập phiếu một cách trực quan.

Bộ Lọc Đa Chiều Nhanh Chóng

Lọc tức thì theo từng chi nhánh, mã kho, khoảng thời gian, nhóm tài khoản hoặc từ khóa tìm kiếm mà không làm đơ giao diện.

An Toàn & Bảo Mật Tuyệt Đối

Kết nối trực tiếp SQL Server trong mạng LAN hoặc VPN nội bộ. 100% dữ liệu tài chính không đi qua bất kỳ cloud server trung gian nào.

Danh Mục Báo Cáo

Hệ Thống Báo Cáo Kế Toán Toàn Diện

Phục vụ công tác quyết toán thuế, báo cáo quản trị và kiểm soát kho chi tiết.

BC001

Bảng Cân Đối Kế Toán

Phản ánh tổng thể tình hình tài sản và nguồn vốn của doanh nghiệp theo mẫu B01-DN (Thông tư 200).

BC002

Báo Cáo Kết Quả Hoạt Động Kinh Doanh

Doanh thu, giá vốn, chi phí quản lý/bán hàng và lợi nhuận thuần từ hoạt động kinh doanh.

BC011

Báo Cáo Lưu Chuyển Tiền Tệ (Chú Long / Quản trị)

Dòng tiền thực tế theo hoạt động kinh doanh, đầu tư và tài chính theo tiêu chuẩn quản trị.

BC013

Báo Cáo Tổng Hợp & Chi Tiết Công Nợ

Tổng hợp công nợ phải thu, phải trả theo từng đối tượng khách hàng và nhà cung cấp.

BC003

Bảng Cân Đối Số Phát Sinh

Kiểm tra số dư đầu kỳ, số phát sinh nợ/có trong kỳ và số dư cuối kỳ của tất cả các tài khoản kế toán.

ACTUAL

Danh Sách Tồn Kho Thực Tế

Truy xuất số dư tồn kho theo (Đơn vị × Kho × Mặt hàng) kèm quy đổi số lượng nguyên/đơn vị nguyên.

Hướng Dẫn Cài Đặt

Khởi Chạy Ứng Dụng Trong 3 Bước Nhanh

Không yêu cầu cài môi trường Python, NodeJS hay bất kỳ thư viện ngoài nào.

1

Tải Tệp Thực Thi (.EXE)

Nhấp vào nút tải xuống để lấy file iPOS_Accounting_Report.exe bản mới nhất về máy tính của bạn.

Tải ngay tệp .EXE →
2

Cài Driver ODBC 17

Ứng dụng cần ODBC Driver 17 for SQL Server để kết nối CSDL iPOS. Chạy lệnh PowerShell bên dưới (hoặc tải trực tiếp từ Microsoft):

winget install Microsoft.ODBCDriverForSQLServer
Tải driver từ Microsoft Web →
3

Mở App & Đăng Nhập

Nhấp đúp chuột vào file iPOS_Accounting_Report.exe. Cửa sổ ứng dụng sẽ tự động mở ra, nhập IP SQL Server và bắt đầu xem báo cáo!

Giải Đáp Thắc Mắc

Câu Hỏi Thường Gặp & Xử Lý Sự Cố

Hướng dẫn giải quyết nhanh các tình huống phát sinh khi chạy ứng dụng trên Windows.

Do file EXE được đóng gói tự động qua CI/CD GitHub Actions và chưa đăng ký chứng chỉ số đắt tiền (Code Signing Certificate), Windows SmartScreen sẽ hiện cảnh báo bảo vệ mặc định. Bạn chỉ cần nhấn vào "More info" (Thông tin khác) → Chọn "Run anyway" (Vẫn chạy) là ứng dụng sẽ mở bình thường.
Máy tính của bạn đang thiếu driver kết nối SQL Server chuẩn. Hãy tải và cài đặt miễn phí gói ODBC Driver 17 for SQL Server (x64) từ trang web chính thức của Microsoft hoặc chạy lệnh winget install Microsoft.ODBCDriverForSQLServer trong PowerShell.
Ứng dụng cần kết nối Internet để tải các tài nguyên giao diện CDN (React / Lucide Icons). Tuy nhiên, toàn bộ dữ liệu kế toán và kết nối CSDL chỉ trao đổi nội bộ trực tiếp giữa máy bạn và máy chủ SQL Server của bạn.
Tại màn hình đăng nhập ban đầu của ứng dụng, bạn chỉ cần nhập thông tin: Máy chủ SQL (Server IP / Port), Tên Database, Tài khoản (Username) và Mật khẩu (Password) được IT hoặc quản trị hệ thống cấp.
